# BozokluHAN Çağrı Kaydedici

Android (10 ve üzeri) için küçük, sempatik, otomatik çağrı kaydedici.

- Gelen / giden aramaları otomatik kaydeder (AAC .m4a)
- Kayıtlar: `Müzik/BozokluHAN Cagri Kayitlari`
- İsim ve numara arama geçmişinden / rehberden otomatik eklenir
- Uygulama içinde dinle, ara, paylaş, sil
- Ses kaynağı seçimi, otomatik hoparlör seçeneği

APK: **Releases** bölümünden `BozokluHAN_Cagri_Kaydedici.apk` indirilir.
